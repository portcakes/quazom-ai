# Quazom AI

## Overview

Quazom is an AI-powered learning platform that automatically generates structured curricula, study plans, and assessments—helping users learn anything through a personalized, guided system.

Instead of asking:
> “What should I learn next?”

Quazom answers:
> **“Here’s exactly what to study today—and why.”**

---

## Core Experience

Quazom transforms any subject into a structured learning experience with:

- 📚 **Curriculum (Course Overview)**
- 📖 **Course Materials (Readings & Resources)**
- 🧠 **Knowledge Checks (Quizzes & Practice)**
- 📅 **Automated Study Scheduling**

Users interact with Quazom like a personalized learning platform—similar to a college course or online class—but dynamically generated and continuously adapting.

---

## Key Concepts

### 1. Curriculum (Primary Interface)

The Curriculum is the central hub for each subject.

- Organized into sections/modules (like a syllabus)
- Each section contains lessons
- Lessons are clickable and track progress
- Users can customize generation via **Educator Context**

---

### 2. Course Materials

A dedicated page for learning resources:

- AI-curated readings
- Videos, articles, references
- Dynamically updated based on user progress

---

### 3. Knowledge Checks

Interactive learning reinforcement:

- Quizzes after lessons
- Immediate feedback
- Helps guide future content generation

---

### 4. Study Scheduling (Core Differentiator)

Quazom automatically generates a study plan across all subjects:

- Users define **study windows**
- Quazom assigns lessons and quizzes into those windows
- Syncs with calendars
- Adjusts around existing commitments

---

## Philosophy

Quazom is built on a simple idea:

> **Learning should be structured, but not rigid.**

It combines:
- The structure of formal education
- The flexibility of self-directed learning
- The adaptability of AI

---

## Advanced System (Future / Power Users)

Quazom is built on an internal framework known as the **5E System**:

- Educators → Curriculum
- Environments → Course Materials
- Experiments → Knowledge Checks
- Exchanges → Interdisciplinary Learning
- Expeditions → Milestones & Assessments

These concepts power the system behind the scenes and may later be exposed through:

- Advanced views
- Knowledge maps (node view)
- Educator tools
